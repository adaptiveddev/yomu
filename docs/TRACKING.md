# Трекинг: Shikimori, AniList, MyAnimeList

С 2.0.0 Yomu отмечает прочитанные главы онлайн-тайтлов в ваших списках на Shikimori, AniList и MyAnimeList.

## Как пользоваться

1. **«Настройки → Трекинг»** — нажмите на сервис: откроется браузер со страницей входа сервиса. После
   «Разрешить» браузер вернёт вас в Yomu (адрес `yomu://…-auth`), и под сервисом появится «Вход: имя».
2. На странице тайтла в каталоге — кнопка **«Трекинг»**: «Найти на …» ищет тайтл в сервисе по названию, выберите
   запись. Привязанной записи можно поменять статус, число прочитанных глав и оценку, открыть её на сайте или
   отвязать (по желанию — и убрать из списка на сайте).
3. Дальше всё само: когда глава дочитана, число прочитанных глав уходит во все привязанные сервисы
   («Обновлять прогресс автоматически» в настройках трекинга). Прогресс только растёт; первая глава ставит статус
   «Читаю» (из «Запланировано», «Отложено», «Брошено») и дату начала, последняя — «Прочитано» и дату окончания.
4. Без сети изменения сохраняются и отправляются, когда сеть вернётся («Отправить изменения» — сразу).

Импорт из Mihon/Tachiyomi переносит и привязки трекеров: после входа в сервис они работают сразу.

Токены входа хранятся в приватных настройках приложения — их нет в резервных копиях и в файле синхронизации; на
каждом устройстве нужно войти отдельно. Привязки (какой тайтл какой записи соответствует) попадают в резервную копию.

С 2.0.4 кнопка **Tracking** доступна и в карточке локальной книги или манги. Откройте файл в библиотеке → карточка книги → Tracking → Link; найдите и выберите запись сервиса. Главы, статус и оценку меняйте вручную: Yomu не определяет номера глав по страницам файла. В разрабатываемой версии привязки также передаются через WebDAV или общую папку отдельным файлом без токенов, оценок и прогресса. На каждом устройстве войдите в сервис и обновите записи; пока данные не загружены, приложение не отправляет начальные значения поверх списка сервиса. Общая папка не гарантирует защиты от одновременных записей: синхронизируйте устройства по очереди.

## Ключи приложения

Сервисы пускают только зарегистрированные приложения: нужен **client ID** (у Shikimori — ещё и **client secret**).
Сборка берёт их из свойств Gradle или переменных окружения:

| Свойство | Сервис |
|---|---|
| `YOMU_ANILIST_CLIENT_ID` | AniList |
| `YOMU_MAL_CLIENT_ID` | MyAnimeList |
| `YOMU_SHIKIMORI_CLIENT_ID`, `YOMU_SHIKIMORI_CLIENT_SECRET` | Shikimori |

```bash
./gradlew assembleRelease -PYOMU_ANILIST_CLIENT_ID=12345 -PYOMU_MAL_CLIENT_ID=… \
  -PYOMU_SHIKIMORI_CLIENT_ID=… -PYOMU_SHIKIMORI_CLIENT_SECRET=…
```

В GitHub Actions (релиз и ночные сборки) это секреты репозитория с теми же именами; без них сборка проходит, просто
ключей в ней нет. В сборке без ключа «Настройки → Трекинг» предлагает ввести свой: «Ключи приложения» — client ID
(и secret для Shikimori). Свой ключ работает вместо встроенного.

### Регистрация

Адрес возврата (redirect URI) должен совпадать **точно**:

| Сервис | Где регистрировать | Redirect URI | Что нужно |
|---|---|---|---|
| AniList | anilist.co → Settings → Developer → Create New Client | `yomu://anilist-auth` | Client ID (число) |
| MyAnimeList | myanimelist.net/apiconfig → Create ID, тип приложения *android* или *other* | `yomu://myanimelist-auth` | Client ID |
| Shikimori | shikimori.io/oauth/applications → «Новое приложение», доступ `user_rates` | `yomu://shikimori-auth` | Client ID и Client Secret |

Как устроен вход: AniList — implicit grant (токен на год, без секрета), MyAnimeList — PKCE (`plain`, как требует
MAL) с обновлением токена, Shikimori — authorization code с секретом приложения, токен на сутки, обновляется сам.

Секрет Shikimori в APK не спрятать — так устроены все открытые клиенты (Mihon делает так же); если ключ отзовут,
пользователи могут ввести свой.

## Ограничения

- На реальном устройстве и с настоящими сервисами вход и обновление прогресса пока не проверялись: проверены
  unit-тестами на MockWebServer (`TrackersTest`: вход, поиск, запись в список, отказ во входе, обновление токена) и
  тестами правил прогресса (`TrackingTest`). Ответы сервисов в тестах написаны по их документации.
- Для локальных файлов главы вводятся вручную, автоматического обновления из процентов и страниц нет. Сервисы ищут по своему каталогу, подходящая запись может отсутствовать.
- Если установлены и release-, и debug-сборка, обе ловят адрес `yomu://`: Android спросит, в какую вернуться —
  выберите ту, из которой входили.
- Kitsu находится в экспериментальной разработке: поиск и работа с записями проверены на тестовом сервере, но вход и изменения через реальный аккаунт ещё не подтверждены. Пароль не сохраняется.
- MangaUpdates, Komga и другие трекеры Mihon не поддерживаются.
