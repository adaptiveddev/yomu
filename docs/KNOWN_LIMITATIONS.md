## Форматы и чтение

- FB2, TXT, HTML, DOCX, MOBI/AZW3 открываются через конвертацию в EPUB: в обычном режиме сложная вёрстка DOCX (таблицы, сноски Word, колонтитулы) упрощается; MOBI — только PalmDOC/KF8-текст без HUFF/CDIC-сжатия.
- **«Разметка страницы» DOCX — приближение к Word**, а не его копия: нет колонок (многоколоночный текст идёт в одну колонку); обтекание плавающих картинок и рамки приближённые; диаграммы, SmartArt и EMF/WMF — заглушки; формулы — простым текстом; примечания и исправления не показываются (виден итоговый текст); шрифты заменяются метрически совместимыми Liberation/Carlito, прочие — системными. Переносы строк и страниц могут немного отличаться от Word (на тестовом документе с LibreOffice расходилась одна строка таблицы на странице). Режим только для просмотра: выделение, словарь и заметки — в обычном режиме.
- DRM не поддерживается: MOBI с DRM отклоняется с понятной ошибкой, зашифрованный EPUB с `META-INF/encryption.xml` отклоняется с ошибкой (без поддержки расшифровки).
- EPUB fixed-layout читается обычным (reflow) движком — свойство `rendition:layout` распознаётся, но отдельного режима нет.
- PDF reflow (2.0.6 WIP): геометрический разбор страницы (XY-cut) — колонки читаются в правильном порядке, колонтитулы с номерами страниц убираются, абзацы собираются по отступам, интервалам и заголовкам, переносы склеиваются. Страницы без текстового слоя показываются картинкой. Художественные вёрстки со сложным обтеканием картинок, таблицы внутри колонок и многоколоночные развороты могут разбираться неточно.
- Озвучивание — системный TTS-движок; качество и языки зависят от устройства.

## Перевод, словари, OCR

- OCR и офлайн-перевод — Google ML Kit: требуют Google Play Services и разового скачивания моделей. Без GMS (например, сборка для F-Droid) эти функции недоступны, онлайн-перевод и словари работают.
- «Google» в онлайн-переводе — публичный endpoint без ключа: возможны лимиты и блокировки. Для стабильной работы — DeepL/LibreTranslate/LLM со своим ключом.
- Лемматизация — правила для en/ru/ja и простое отсечение окончаний для остальных языков; без морфологических словарей. Для японского нет токенизатора (Kuromoji): слово под пальцем определяется деинфлексией по правилам и поиском самого длинного совпадения в JMdict.
- Перевод книги с карточки создаёт новую EPUB-копию по сохранённой книге (не по черновику редактора) — всей книги или, с 2.0.0, выбранных глав; перевести выбранные главы прямо в черновике можно в редакторе.

## Редактор

- Манга: перевод страницы (OCR → перевод → вписывание, с 2.0.0) закрашивает оригинал прямоугольником блока — цветом облачка, белым или чёрным; кисти клина для фигурных облачек и текста поверх рисунка нет. Шрифт перевода — системный, без выбора гарнитуры; вертикальный японский текст распознаётся ML Kit хуже горизонтального. Есть: порядок/удаление/вставка страниц, поворот, обрезка полей (авто и вручную), яркость/контраст/гамма/ч-б, разделение разворотов, склейка, пережатие, обложка, ComicInfo.xml.
- Поиск/замена в EPUB работает внутри текстовых узлов: совпадение, разорванное тегами (`<b>сло</b>во`), не найдётся; режим «в разметке» ищет по исходному XHTML.
- Не-EPUB книги сохраняются как EPUB, CBR/CB7/папки — как CBZ. «Заменить оригинал» для связанных (не скопированных) файлов требует права записи SAF; иначе сохраняется копия.
- Визуальный редактор главы (с 2.0.0) рассчитан на текст и простое оформление (абзацы, заголовки, списки, цитаты, ссылки, картинки книги); сложную вёрстку (таблицы, SVG, MathML, классы и стили отдельных элементов) надёжнее править в исходном XHTML. Вставка из буфера — только текстом. В Android WebView редактор пока не проверялся.
- Манга: нет объединения нескольких глав в том и разделения тома; экспорт — CBZ, PDF и EPUB, без «папки с картинками».
- Пакетная правка метаданных (с 2.0.0) меняет данные библиотеки Yomu, а не OPF внутри файлов: чтобы метаданные попали в сам EPUB, книгу нужно сохранить через редактор.

- Каталог и глобальный поиск по умолчанию показывают только язык устройства и английский; остальные языки выбираются в «Каталоге» → «Языки» (выбор сохраняется).
- Фильтры источника — только те, что даёт само расширение. Например, у NHentai.xxx нет фильтра по числу страниц (и число страниц не приходит в списке результатов), а языки — отдельные источники «NHentai.xxx» (EN, JA, ZH, ALL).
- Расширения из репозиториев загружаются через `DexClassLoader` из приватной папки; это работает на Android 8–15, но Google Play запрещает загрузку исполняемого кода — для Play-сборки репозитории расширений нужно отключить.
- `QUERY_ALL_PACKAGES` требует обоснования в Google Play.
- Встроенные публичные источники (Gutenberg, Standard Ebooks, Feedbooks, ManyBooks, Gutendex, Open Library/Internet Archive) и встроенные расширения зависят от сайтов; при изменениях сайта источник перестанет работать до обновления (расширения обновляются из репозитория с тем же ключом подписи).
- Cloudflare-проверка (и ответы 403/503 расширений) проходится вручную в WebView; автоматического решения нет. Автоматические повторы помогают только при временных ошибках: тайм-ауты, обрывы связи, 429, 5xx.
- «Скачивать новые главы» срабатывает только для тайтлов из библиотеки и только по итогам проверки обновлений (по расписанию или вручную); новые главы, найденные при открытии тайтла, ставятся в очередь вручную. «Докачивать при чтении» — тоже только для тайтлов из библиотеки. Загрузки соблюдают «только по Wi-Fi»: без Wi-Fi очередь ждёт.
- Не больше 2 одновременных загрузок с одного сайта — значение зафиксировано, в настройках не меняется (общее число параллельных загрузок настраивается).
- Состояние источников («не отвечает», «отвечает медленно») хранится только в памяти: после перезапуска приложения подсказки пропадают до новых ошибок.
- Порядок чтения глав (читалка, «Продолжить», «Скачать следующие», автозагрузка) определяется по номерам глав и порядку источника. «Одна версия главы» и выбор версии своей команды опираются на номера: главы без номера считаются разными, а у источников, которые нумеруют главы заново в каждом томе, копии от разных команд не объединяются. Для источников с совсем необычной нумерацией порядок может ошибаться — сортировка «Как в источнике» показывает список как есть, но на навигацию в читалке не влияет.

## Приложение

- **Счётчик трафика — оценка.** Считается трафик самого приложения (запросы каталога, обложки, страницы, загрузки, расширения) по размеру заголовков и тел ответов «по проводу»; страницы встроенного браузера (WebView, проверка Cloudflare) и системные загрузки не учитываются, поэтому цифры могут быть меньше, чем в настройках Android. Сеть считается мобильной, если Android помечает её как лимитную (так же считается раздача с телефона и лимитный Wi-Fi).
- **Экономия трафика** применяется к главе при её открытии: если сеть сменилась во время чтения, предзагрузка поменяется со следующей главы. Обложки, которых нет в кеше, в мобильной сети при выключенном «Загружать обложки в мобильной сети» не показываются до подключения к Wi-Fi.

- Блокировка «сразу» срабатывает и после возврата из системного выбора файлов, если он был открыт дольше ≈1,5 с.
- У экрана «Поиск слова» (открывается из «Найти в Yomu» в других приложениях) нет стрелки «назад» — закрывается системным жестом.
- Синхронизация (2.0.0–2.0.4 WIP): удаления выделений, заметок, закладок, слов, вкладок и онлайн-тайтлов передаются отметками. С 2.0.4 (WIP) книги тоже передаются удалениями, если включена синхронизация файлов и настройка удалений: неизменённая копия удаляется вместе со своими записями и файлом библиотеки, изменённая — сохраняется с конфликтом на экране «Конфликты синхронизации»; блобы на сервере не удаляются, папки изображений удалениями не покрываются. Изменённые файлы обычных книг принимаются явно («принять мою версию» / «загрузить другую»): перепривязка прогресса, аннотаций и трекеров журналируется и докатывается после сбоя; повторные изменения (включая запись выделений в PDF самим приложением) публикуются автоматически. Legacy-папки (`dir:`) переводятся на стабильные идентификаторы по действию пользователя, другие устройства следуют за маркером. Изменения страниц папок не останавливают остальные папки: неоднозначная папка пропускается с записанной проблемой, публикация/принятие версии сбрасывает позиции на изменённых/удалённых страницах с отчётом (аннотации остаются «висячими», читатель отказывает в устаревших переходах). Нужны сильные ETag и условная запись, HTTPS рекомендуется; сервер видит содержимое. Копирование не шифруется приложением, требует места и трафика. Удалённые локально книги не возвращаются на том же устройстве; устройства со старыми версиями не знают о маркерах принятия версий и удалений книг — обновите все. Прогресс онлайн-глав по-прежнему «последний записавший выигрывает». Реальные устройства, WebDAV-серверы и облачные провайдеры не проверялись — только моделируемые обмена и MockWebServer.
- Выделения в PDF-файле (2.0.0): Yomu пишет аннотации Highlight/Underline/StrikeOut инкрементальным обновлением в конец файла и заменяет своё обновление, пока файл им заканчивается; если файл после этого изменила другая программа, следующее обновление дописывается после её изменений (файл растёт). Зашифрованные PDF и PDF без права записи не меняются — выделения остаются только в базе. Аннотации, нарисованные другими программами, Yomu показывает при отрисовке страницы, но в свои выделения не превращает.
- Виджет «Продолжить чтение» обновляется, пока жив процесс приложения, и по расписанию системы (раз в 6 часов); после принудительной остановки приложения новое появится после следующего запуска.
- Восстановление из резервной копии записывает строки поверх текущих (записи с тем же id заменяются, остальные остаются) — без «умного» слияния.
- Обновление: докачка работает при наличии контрольной суммы; сертификат проверяется до установщика, но смена ключа подписи пока не поддерживается; Android дополнительно проверяет установку.
- Release-APK без переменных `YOMU_KEYSTORE_*` подписывается debug-ключом — для публикации нужен свой keystore.
- 1.1.0 подписана другим ключом, чем 1.0.0 (ключ 1.0.0 не сохранился), а APK 1.2.0 из этого релиза — новым ключом (keystore 1.1.0 в исходниках не хранится): поверх старой версии он не встанет — нужно удалить её, предварительно сделав резервную копию, и восстановить копию после установки. Либо собрать 1.2.0 своим keystore от 1.1.0.
- Статистика считает время по сеансам чтения: после 5 минут без действий сеанс завершается; время в режиме «Разметка страницы» тоже учитывается.
- Собираются только arm64-v8a и x86_64 (нет armeabi-v7a для старых 32-битных устройств).
