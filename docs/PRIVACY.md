# Политика конфиденциальности Yomu

*Действует с версии 1.0.0.*

**Yomu ничего не собирает и никуда не отправляет без вашего действия.** В приложении нет рекламы, аналитики, трекеров слежки, учётных записей и собственного сервера. (Трекинг чтения в Shikimori, AniList и MyAnimeList — это ваши списки на этих сайтах; он работает, только если вы вошли в сервис, см. ниже.)

## Что хранится на устройстве

Библиотека, файлы книг, прогресс чтения, заметки, слова, словари, настройки, кеш обложек и журнал ошибок хранятся только в памяти устройства (в папке приложения или в выбранных вами папках). Резервные копии и файлы синхронизации записываются только в папки, которые вы выбрали, или на ваш WebDAV-сервер. С 2.0.0 выделения в PDF по умолчанию записываются и в сами PDF-файлы (выключается в «Настройки → Манга и PDF»).

## Когда приложение выходит в сеть

Только по вашему действию или по расписанию, которое вы включили:

| Действие | Куда отправляются данные |
|---|---|
| Просмотр каталога, поиск, скачивание книг и глав | выбранный источник (OPDS-каталог, Project Gutenberg, Standard Ebooks, Feedbooks, ManyBooks, Gutendex, Open Library/Internet Archive, MangaDex, установленные вами расширения) |
| Проверка обновлений глав (если включена) | источники тайтлов из вашей библиотеки |
| Онлайн-перевод | выбранный вами сервис: Google Translate, DeepL, LibreTranslate или указанный вами LLM-сервер — отправляется только переводимый текст |
| Онлайн-словарь (если включён) | dictionaryapi.dev или Wiktionary — отправляется только искомое слово |
| Скачивание языковых пакетов и OCR-моделей | серверы Google (ML Kit) |
| Расширения из репозитория | адрес репозитория, который вы добавили |
| Поиск в интернете и свои кнопки панели выделения | сайт/приложение, которое вы выбрали |
| Трекинг (если вы вошли в Shikimori, AniList или MyAnimeList и привязали тайтл) | этот сервис — вход через его страницу в браузере, затем поиск тайтла по названию, статус, число прочитанных глав, оценка и даты привязанных тайтлов |
| Синхронизация через WebDAV (если выбрана) | указанный вами сервер — файл `yomu-sync.json`: прогресс, статусы и вкладки книг (по хешу файла), выделения, заметки, закладки, слова, по желанию онлайн-библиотека и отметки удалений; если отдельно включена синхронизация файлов книг, также сами файлы книг и индекс `yomu-books.json`. Приложение не шифрует эти данные для сервера; используйте HTTPS |
| Проверка и скачивание обновлений Yomu (по нажатию «Проверить обновления» или раз в день, если включена автопроверка; по умолчанию выключена) | api.github.com и github.com — запрашивается только список релизов, никаких данных о вас и вашей библиотеке не отправляется |

Ключи API (DeepL, LibreTranslate, LLM), логины OPDS и WebDAV, токены входа трекеров хранятся только на устройстве и передаются только соответствующему сервису. Токены трекеров не попадают ни в резервные копии, ни в файл синхронизации.

## Разрешения

- **Интернет и состояние сети** — для перечисленных выше действий и режима «только по Wi-Fi».
- **Уведомления, фоновые задачи (foreground service), запуск после перезагрузки** — загрузки, обновления, автокопии и напоминания.
- **Биометрия** — разблокировка приложения (отпечаток не покидает систему Android).
- **Список установленных приложений (`QUERY_ALL_PACKAGES`)** — только чтобы найти установленные расширения-источники Yomu; список никуда не отправляется.
- **Установка приложений (`REQUEST_INSTALL_PACKAGES`)** — только чтобы открыть системный установщик для скачанного обновления Yomu. Установку всегда подтверждаете вы; APK перед этим сверяется по SHA-256 с файлом `SHA256SUMS.txt` из релиза.
- Доступ к файлам — только через системный выбор файлов/папок (SAF), к тем, что вы выбрали.

## Журнал ошибок

Сбои записываются в локальный журнал. Он отправляется только если вы сами нажмёте «Поделиться» в экране журнала.

## Дети

Приложение не собирает данные, поэтому не собирает и данные детей. Контент 18+ из источников скрыт по умолчанию.
