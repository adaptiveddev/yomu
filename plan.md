**Продукт:** одно приложение с тремя режимами: читалка (книги, ранобэ, PDF, манга), редактор (правка книг и манги) и каталог источников (как в Mihon). ## UI/UX: принципы и экраны (действует на всех этапах)

Агент делает интерфейс сразу как продуманный продукт, а не «потом причешем». Дизайн-система создаётся на этапе 0 в модуле `core:ui`, и каждый новый экран собирается только из её компонентов.

### Принципы

1. **Чтение прежде всего.** В читалке ничего не мешает тексту: панели скрыты, появляются по тапу в центре и скрываются сами через несколько секунд.
2. **Одна рука.** Основные действия в нижней трети экрана: нижняя панель навигации, шторки снизу вместо диалогов по центру, крупные зоны нажатия (не меньше 48dp).
3. **Минимум шагов.** Сохранить слово, поставить закладку, выделить цитату: не больше двух касаний.
4. **Предсказуемость.** Единый Material 3, одинаковые жесты и иконки на всех экранах, привычные паттерны Mihon, Moon+ Reader, Librera.
5. **Мгновенный отклик.** Скелетоны вместо спиннеров, плавные анимации (до 300 мс), оптимистичные обновления (отметка «прочитано» без ожидания).
6. **Всё настраивается, но с хорошими значениями по умолчанию.** Новичку не нужно открывать настройки.

### Дизайн-система (`core:ui`)

- [ ] Цвета: Material You (динамические), светлая, тёмная, AMOLED-чёрная; контраст текста не ниже WCAG AA
- [ ] Типографика: шкала Material 3, отдельная шкала для текста книги
- [ ] Формы, отступы, высоты на сетке 4/8dp; единый набор иконок (Material Symbols)
- [ ] Готовые компоненты: карточка книги и манги, плитка обложки, шторка (BottomSheet), поле поиска, чипы фильтров, пустое состояние, состояние ошибки с кнопкой «Повторить», скелетон, снекбар с «Отменить»
- [ ] Анимации: переходы между экранами (shared element для обложки: из сетки на страницу тайтла и в читалку), плавное появление панелей читалки
- [ ] Предпросмотр всех компонентов в `@Preview` (светлая/тёмная, крупный шрифт)

## 4. Этап 4: выделение текста, меню с кнопками, цитаты, заметки, закладки

### Контекстное меню выделения (ключевая функция)

При выделении текста (EPUB, PDF, TXT, FB2, текст в OCR-режиме манги) вместо системного меню показывается **собственная плавающая панель** над выделением. Панель прокручивается по горизонтали, если кнопки не помещаются, и имеет кнопку «⋯» для остальных действий. Набор и порядок кнопок настраиваются в Настройках (включить, выключить, переставить).

| Кнопка | Действие |
| --- | --- |
| Цвета выделения | 5 цветов в один тап (жёлтый, зелёный, синий, розовый, фиолетовый), сохраняет выделение |
| Подчёркивание / зачёркивание | Альтернативные стили выделения |
| Заметка | Открывает поле ввода заметки к выделению |
| Цитата | Сохраняет цитату в коллекцию цитат (с названием книги, главой, позицией) |
| Значение | Мини-окно со словарной статьёй слова (офлайн, при отсутствии онлайн) |
| Перевести | Перевод выделенного фрагмента в нижней шторке (движок и язык меняются прямо там) |
| Сохранить слово | В один тап добавляет слово с контекстным предложением в словарь пользователя |
| Копировать | В буфер обмена |
| Поделиться | Системное меню; опция «Поделиться цитатой картинкой» (карточка с текстом, названием и автором) |
| Искать в книге | Поиск выделенного по всей книге |
| Искать в интернете | Выбранная поисковая система, Wikipedia, свой URL-шаблон |
| Читать вслух | TTS с этого места |
| Выделить всё предложение / абзац | Быстрое расширение выделения |
| Закладка | Закладка на позицию выделения |
| Пользовательские | Свои кнопки: шаблон URL с подстановкой `{text}`, передача текста в стороннее приложение (например AnkiDroid, Яндекс Переводчик) |

**Жест «тап по слову»:** одиночное нажатие и удержание на слове открывает мини-панель (значение + перевод + «Сохранить») без полного выделения. Поведение (тап, удержание, двойной тап) настраивается.

## 6. Этап 6: режим редактора (отдельный режим, и текст, и манга)

Редактор открывается отдельной кнопкой из меню книги и из читалки. Работает **всегда над копией** книги (оригинал не меняется, пока пользователь не нажмёт «Сохранить как…» или «Заменить оригинал»). Есть история изменений (undo/redo, минимум 50 шагов) и автосохранение черновика.

### Редактор книг (EPUB, FB2, TXT)

- [ ] Метаданные: название, автор(ы), серия, номер, язык, описание, теги, издатель, обложка (выбор из галереи или камера)
- [ ] Структура: оглавление (добавить, удалить, переименовать, перетащить главы), порядок глав, разделение и объединение глав
- [ ] Правка текста главы: визуальный (WYSIWYG: жирный, курсив, заголовки, списки, ссылки) и исходный режим (HTML/XHTML с подсветкой синтаксиса)
- [ ] Поиск и замена по главе и по всей книге (обычный текст и regex), счётчик замен, предпросмотр
- [ ] Работа с картинками: заменить, удалить, добавить иллюстрацию
- [ ] Стили (CSS): просмотр и правка таблицы стилей, готовые пресеты очистки («убрать встроенные шрифты и цвета»)
- [ ] Очистка: удаление пустых абзацев, лишних пробелов, исправление кавычек и тире, автоперенос
- [ ] Проверка корректности EPUB (валидация структуры, битые ссылки, отсутствующие ресурсы) со списком проблем и автоисправлением
- [ ] Конвертация: TXT/FB2/HTML → EPUB, EPUB → TXT/PDF (простой)
- [ ] Перевод книги: выбрать главы → перевод через выбранный движок → сохранение как новый EPUB или двуязычный EPUB; прогресс в фоне через WorkManager
- [ ] Пакетная правка метаданных нескольких книг

### Редактор манги (CBZ, ZIP, папка)

- [ ] Менеджер страниц: сетка миниатюр, перестановка, удаление, вставка, поворот, разделение разворота на две страницы, объединение
- [ ] Метаданные: ComicInfo.xml (название, серия, номер, автор, жанр, язык), обложка
- [ ] Обрезка полей и кадрирование (авто и вручную), коррекция яркости, контраста, баланса уровней, перевод в градации серого
- [ ] Изменение размера и пересжатие (WebP/JPEG, качество, максимальная ширина) для экономии места, пакетно по всей главе
- [ ] Клин (очистка): кисть и заливка для закрашивания текста в облачках (цвет по пипетке, размер кисти, undo)
- [ ] Тайпсет: добавление текстовых блоков поверх страницы (шрифт, размер, цвет, обводка, выравнивание), перетаскивание, поворот
- [ ] Перевод в редакторе: OCR выбранной области → перевод → вставка текстового блока; пакетный режим «перевести всю главу» с ручной корректировкой
- [ ] Экспорт: CBZ, PDF, папка с картинками, EPUB (манга-версия)
- [ ] Объединение нескольких глав в один том и разделение тома на главы

### Общее для редактора

## 7. Этапы 7–8: источники как в Mihon, каталог, поиск и скачивание

### Этап 7. Система источников и каталог

Приложение **не содержит кода конкретных пиратских сайтов**. Оно содержит механизм источников (как в Mihon): источник описывается интерфейсом, а подключается встроенным модулем или внешним расширением, которое пользователь ставит сам. Встроенные источники только легальные.

**Интерфейс источника (`source-api`):**

- `id`, `name`, `lang`, `supportsLatest`, `supportsSearch`
- `getPopular(page)`, `getLatest(page)`, `search(query, filters, page)`
- `getDetails(item)`, `getChapters(item)`, `getPages(chapter)` для манги и `getContent(chapter)` для ранобэ
- `getDownloadLinks(book)` для книг (OPDS-стиль)
- Список фильтров (жанры, статус, сортировка, год) описывается декларативно, UI строится по нему автоматически

**Задачи:**

- [ ] Модуль `source-api` с интерфейсами и моделями (`SManga`, `SChapter`, `SBook`, `Page`, `FilterList`)
- [ ] Загрузка внешних расширений: отдельные APK с общим интерфейсом через `PackageManager` и `DexClassLoader`/изолированные classloader; экран «Расширения» (установленные, доступные, обновления); подпись и предупреждение об источнике; **репозитории расширений** добавляются пользователем по URL (JSON-индекс)
- [ ] Встроенные источники: **OPDS** (любой OPDS 1.2/2.0 каталог, например Project Gutenberg, Standard Ebooks, Internet Archive, Flibusta-подобные по желанию пользователя через свой адрес), **MangaDex** (официальный API), **Локальный источник** (папка на телефоне со структурой «Манга/Глава»)
- [ ] Вкладка «Каталог»: список источников, закреплённые, фильтр по языку; экран источника с вкладками «Популярное», «Новое», «Поиск»; сетка обложек с бесконечной прокруткой (Paging 3)
- [ ] Панель фильтров (жанры, теги, статус, сортировка), сохранение последнего фильтра
- [ ] Глобальный поиск по всем источникам сразу: результаты по группам-источникам, загружаются параллельно
- [ ] Страница тайтла: обложка, описание, автор, жанры, статус, список глав с отметками «прочитано» и «скачано», кнопка «Добавить в библиотеку», «Продолжить», сортировка глав
- [ ] «Избранное» (библиотека манги), категории, обновления глав: WorkManager проверяет новые главы по расписанию (по умолчанию раз в 6 часов; Wi-Fi или любая сеть, на выбор), уведомление о новой главе, вкладка «Обновления»
- [ ] «История»: недавно прочитанное с возвратом на место
- [ ] Миграция тайтла между источниками (переносит прогресс и отметки)
- [ ] Чтение манги прямо из онлайн-источника (стриминг страниц, предзагрузка, кеш) тем же движком, что и локальная
- [ ] Чтение ранобэ из онлайн-источника: глава подгружается в тот же текстовый движок со всеми функциями (выделение, перевод, словарь)
- [ ] Обработка ошибок сети, повтор, понятные сообщения, Cloudflare/WebView-проверки: открытие страницы в WebView для прохождения проверки и перенос cookies
- [ ] Тесты источников на фейковых ответах сервера (MockWebServer)

### Этап 8. Поиск и скачивание книг, загрузки
